TenClip. 网球视频理解 & 资讯平台

在有限本机显存上跑通「视频剪辑 + 网球动作多模态分析」，并向外延伸出网坛资讯抓取、 内容运营后台与小红书笔记采集。本页用流程图呈现整体架构、数据流与未来展望。

Stroke Extract

击球片段提取：去等待 / 长视频

输入整段网球视频，自动保留击球与回合画面，剪掉换边、等待、捡球等。 采用 ffmpeg 流式分析（适合 200MB+），非全片 VLM；可选 Qwen2-VL 二次过滤。

📱

iPhone MOV / 长视频

源为 HEVC/MOV 时自动重编码为 H.264 + yuv420p + faststart，避免 Windows 播放器无法打开。勿用 --copy。

🎛️

调参

--motion-percentile 默认 72（越低保留越多）；--merge-gap 默认 2.8s；误检多开 --vlm-filter。

示例（WSL 访问 Windows 视频）：python scripts/extract_stroke_clips.py /mnt/c/Users/you/Pictures/match.MOV --out /mnt/c/Users/you/Pictures/match_strokes_only.mp4 · 先 --analyze-only --report-out data/stroke_report.json 看保留比例。

① 去等待 / 切片

extract_stroke_clips.py 自动保留击球段（可选）；slice_match_to_clips.py 按表切短片 + manifest。

② 抽帧建数据集

build_vlm_dataset_from_videos.py：线上同款抽帧 → data/vlm_images/<id>/，--register-key 自动注册；🆕 --dry-run 校验+预览、--limit 试跑。

🧪

mock 快速打通

generate_mock_vlm_datasets.py 造多模态 SFT/DPO；materialize_mock_vlm_images.py 落盘占位图，端到端冒烟。

🔌

③ 接回推理

adapter → saves/qwen*/lora/；合并后 TENCLIP_VLM_MODEL 指向本地目录即生效（后端 LLaMA-Factory / Transformers 可切）。

运行示例：conda activate tenclip → python scripts/slice_match_to_clips.py --video match.mp4 --segments segments.jsonl --manifest-out data/manifest_sft.jsonl --mode sft → python scripts/build_vlm_dataset_from_videos.py --mode sft --manifest data/manifest_sft.jsonl --out data/tennis_vlm_sft.json --register-key tennis_vlm_sft → llamafactory-cli train configs/train/qwen2_vl_2b_qlora_sft_mm.yaml。

Outlook

延伸方向与展望

在现有「本地视频理解 + 资讯内容站」双链路基础上，可向以下方向延伸。

① 模型与推理：从通用到网球专精

用真实视频抽帧构建 SFT/DPO 数据，沉淀网球域 LoRA；引入「证据先行」时序对齐，降低少帧幻觉；探索更大上下文与多视角输入。

② 推荐：内容召回 → 协同过滤 → 混排探索

在规则排序稳定后叠加隐式反馈 CF（ALS / item-based），再做「CF 分 + 内容相关 + 时效」混排与多臂探索，缓解冷启动。

③ 内容生态：多源采集与合规

小红书之外扩展更多平台采集，统一 NoteInfo 抽象；坚持 RSS 白名单优先、按需深爬，沉淀来源质量分层与审计。

④ 产品形态：从 Demo 到可运营平台

打通「资讯 → 球员 → 比赛 → 视频分析」的内容图谱；用户画像驱动个性化首页；后台支持定时任务与内容质量治理看板。

⑤ 工程化：可观测、可扩展

SQLite → PostgreSQL 平滑迁移；引入任务队列与调度（替代 cron）；接入日志/指标，容器化与 CI 构建前端制品。

⑥ 互动：训练计划与社区

将动作分析结论转为可执行训练微周期，结合用户反馈形成进步追踪；引导 UGC 与教练点评，形成数据飞轮。

文档入口：readme.md · subprojects/README.md · env.example

快速启动：conda activate tenclip → 主应用 bash run-wsl.sh； API uvicorn subprojects.core_api.app:app --port 8000； 用户站 cd web && npm run dev； 击球提取 python scripts/extract_stroke_clips.py match.MOV --analyze-only。
