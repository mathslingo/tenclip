# UI 重构说明 (2026-08-10)

## 主要改动

### 1. Tab栏重构
- **新顺序**：分析 | 发现 | 我
- **使用原生 TabBar**：性能更好，体验更流畅
- **合并功能**：击球剪辑和动作分析统一到"分析"页面

### 2. 开发者模式
- **位置**："我" → 设置（右上角）→ 开发者模式开关
- **默认状态**：关闭
- **影响范围**：
  - 分析页面：开发者模式显示"实时关键点检测"和后端状态
  - 用户模式：只显示核心功能（击球剪辑、动作分析）

### 3. 新页面结构
```
pages/
├── analyze/         # 统一的分析入口页（新增）
├── feed/           # 发现页
├── me/             # 我的页面（增加开发者模式开关）
├── stroke-extract/ # 击球剪辑（保留）
├── action-analyze/ # 动作分析（保留）
├── pose-detect/    # 姿态检测选择页（开发者功能）
├── pose-live/      # 原生摄像头姿态检测（开发者功能）
└── pose-webview/   # H5姿态检测（开发者功能）
```

### 4. 用户体验优化
- ✅ **更简洁的入口**：用户模式只显示常用功能
- ✅ **更清晰的层级**：分析 → 具体功能
- ✅ **更友好的提示**：功能卡片配有描述和图标
- ✅ **保留开发者工具**：通过开发者模式切换

### 5. 开发者功能
开启后可见：
- 实时关键点检测入口
- 后端状态监控
- 详细日志输出
- 测试工具

## 使用说明

### 普通用户
1. 打开小程序，默认进入"分析"页
2. 选择"击球剪辑"或"动作分析"
3. 查看"发现"页的网球资讯
4. "我"页面管理个人信息和收藏

### 开发者
1. 进入"我" → 点击右上角"设置"
2. 开启"开发者模式"开关
3. 返回"分析"页，可见"实时关键点检测"和后端状态
4. 可以测试和调试各项功能

## 技术说明

- **TabBar**：使用微信小程序原生 tabBar，性能最优
- **状态管理**：开发者模式状态保存在 `wx.storage`
- **页面导航**：Tab 页面使用 `wx.switchTab`，其他使用 `wx.navigateTo`
- **样式统一**：所有页面使用统一的设计系统
